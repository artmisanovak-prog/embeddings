# Embeddings · Semantic Gap

Experimentální repozitář projektu **Chceš myš? Slovník mezer**.

## Otevřít

- [Experimentální rozcestník (GitHub Pages)](https://artmisanovak-prog.github.io/embeddings/doma/)
- [Pracovní prostor doma/](doma/)
- [README experimentu](doma/README.md)

První fáze je **BASELINE bez MAPY VÝZNAMU**. Používá jeden multimodální model pro obraz, text a obraz + text. Cílem je získat srovnávací výchozí reprezentace a pozorovatelné výstupy modelu. Autorská MAPA VÝZNAMU a topologické zadání budou přidány až v navazující experimentální fázi.

Výsledky se průběžně ukládají na Google Drive. ZIP archivy lze následně předat k zařazení do tohoto repozitáře.
